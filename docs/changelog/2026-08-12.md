## 2026-08-12

- Added ERP order sync retry (3 attempts with backoff) and a manual "Resend to ERP" admin action for orders that exhaust their retries, restoring the order's pre-failure status on success.
- Fixed the Magister API client hard-coding `RO` as the invoice/delivery country code instead of using the order's actual billing/shipping address country.
- Fixed `Locality::exists()` reporting false-positive address matches under MySQL's case-insensitive collation by re-verifying candidates in PHP with a strict comparison.
- Fixed same-second order activity entries sorting non-deterministically in `Order::getActivitiesByStatuses()` and the admin activity log feed; both now tie-break by `id`.
