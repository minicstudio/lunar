## 2026-10-28

- Staff can split an eligible order into two or more orders from a preview. Shipping can be edited on each new order. A coupon goes to one order even when that order is below the original minimum, even when the coupon has since expired, the original order already used up its limit, or it no longer lists the assigned products, and a loyalty redemption goes to one order. The original order becomes `split` and drops out of report revenue. Stock still decreases once when the order is received. The order can be split after that, and the split does not take those units again. Canceling a new order restores its quantities.
- A host that publishes `lunar.orders.statuses` must add `split` with `exclude_from_reports` and empty mailers and notifications. An order that is not split is still sent to the ERP once when the host dispatches `OrderPlacedEvent`. An offline new order uses that same queued send, and becomes `failed-erp-sync` when the retries are exhausted.
