## 2026-10-06

- `ProductVariant::getThumbnail()` (and `getThumbnailImage()`) now returns the variant's primary image or its first image by pivot position; if the variant has no images, the primary or first general image (product images not assigned to any variant); only when neither exists, the primary or first image among all product media, ordered by `order_column`. Previously it fell back straight to the product's primary image, and returned `null` when no image was primary. The new `ProductVariant::generalMedia()` returns the general images (LFP-504).
- `ProductVariant::images()` now uses the `Lunar\Models\MediaProductVariant` pivot model, so attaching, detaching a variant image or changing its primary flag or position through the pivot fires model events that can be observed. `saved` covers creation and updates. Filament's direct drag-and-drop reordering bypasses these events; integrations caching thumbnails must reindex after such a reorder when it changes the fallback image (LFP-504).
