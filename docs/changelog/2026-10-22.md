## 2026-10-22

- Added a `test-order` ("Test Order") order status for orders that were only placed for testing (LFP-889).
- Order statuses can now set `exclude_from_reports => true`. `Order::reportable()` leaves orders in those statuses out of the results. `test-order` is flagged by default.
- Dashboard order stats, order charts and the popular products table now leave out excluded orders, and so do the customer stats (total orders, average spend, total spend). The order list and the latest orders table still show them.
