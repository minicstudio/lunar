## 2026-10-09

- Added the **Feedback** package (`lunarphp/feedback`): a `lunar_feedback` table with one score and optional comment per order and feedback type (unique `order_id` + `type`; rows without an order are reserved for later flows), config `lunar.feedback` (`FEEDBACK_ENABLED`, scale, threshold, type keys, comment length, rate limit), and `Order` relations `feedback` / `shoppingExperienceFeedback`.
- When feedback is enabled, the admin shows a read-only **Feedback** list under Sales (filter by type and score), the orders list gets a **Feedback score** column after the customer type, and the order detail summary shows the score and comment of the checkout shopping-experience feedback. Labels are translated in EN/HU/RO.
