## 2026-11-05

- Added the `lunarphp/analytics` package (LFP-925) for measuring and reporting features. It has one provider, one Filament plugin (`AnalyticsPlugin`, "Analytics" navigation group), one config file (`config/lunar/analytics.php`, one section per feature) and one permission state. Its first feature is traffic sources: where storefront visitors come from and which source leads to carts and orders.
- Added traffic source recording (LFP-925). The `RecordTrafficVisit` route middleware stores one `lunar_traffic_visits` row per visit (source, medium, campaign, referrer host, landing path; no personal data) on the first storefront page view of a session, or when campaign parameters change the source. The source comes from `utm_source`, ad click ids, known referrer hosts, other hosts or direct, configurable per shop (`ANALYTICS_TRAFFIC_ENABLED`, referrer hosts, click ids, bot pattern, classifier class). Nothing is recorded in the admin panel, in staff sessions, for bots or prefetches, or for visitors whose active cart already has a source.
- Added cart and order attribution (LFP-925). New carts get `meta.traffic_source` from the current visit (first touch). Orders keep it with the cart meta, and split orders now copy it too (`SplitOrder::COPIED_META_KEYS`).
- Added the admin **Traffic sources** report (LFP-925) in the Analytics group, for admins and staff with the new `analytics:traffic-sources` permission (created on migrate, no role). For a chosen period it shows visit, cart and order totals, order value and order rate, visits by source, visits per day, a per-source funnel with an "Unknown" row for orders without a source, and the most visited landing pages.
- Order line `without_coupon` price accessors reverse loyalty redemption as well as coupons, so success/history/email line prices match the checkout summary when points were redeemed.
