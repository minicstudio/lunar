## 2026-09-28

- BXGY free gifts now update `subTotalDiscountedWithoutCoupon*` / `discountTotalWithoutCoupon` so storefront Subtotal (and cart total) exclude gift full price when `automatically_add_rewards` is off or gifts are auto-added.
- BXGY tops up only *unmet* selected gifts when a new parent is added — existing gift lines are deducted from selection demand so a qty-2 parent does not lose its second gift (fixes list `1/2` while the modal still shows two picks).
- BXGY auto-add tops up remaining single-reward gift budget after qty increase even when `selected_gift_rewards` meta is already present (no longer blocked by explicit selection meta).
- Multi-reward BXGY no longer random-adds every configured reward when `automatically_add_rewards` is on; gifts are granted from `selected_gift_rewards` (storefront modal). Unit tests cover no-selection vs explicit pick.
- BXGY removes gift lines on recalculate when the cart falls below `min_qty` (or has no qualifying parents), instead of leaving orphan free gifts.
- BXGY gift trim updates in-memory cart lines via `setRelation('lines', …)` so a later cart `save()` does not try to persist a non-existent `lines` column.
