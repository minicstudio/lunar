## 2026-11-19

- Added an AI-assisted product import (Excel/CSV) to the admin, with column mapping review, category and brand review, preview, and queued import into the catalog (LFP-954). New package `packages/product-import` (`Lunar\ProductImport`), turned on with `PRODUCT_IMPORT_ENABLED` and the `catalog:import-products` staff permission; the host registers `ProductImportPlugin`. Staff upload an XLSX, XLS, or CSV file from **Import** on the product list; every sheet is staged in the package's own tables, one AI request per sheet suggests the column mapping (headers, column statistics, and a few samples only; provider, model, and optional own key from `PRODUCT_IMPORT_AI_*`), and nothing reaches the catalog until staff approve the preview. Brands, categories, options, and option values are created first, then products, variants, and base prices in one transaction per product group; existing variants are matched by SKU or EAN, so importing a file again does not create duplicates. Mappings can be saved as profiles and are offered for files with matching headers. Failed rows can be downloaded as CSV, corrected, and retried; `product-import:prune` removes staged rows and files after the retention period. New dependencies: `maatwebsite/excel` ^4.0 and `laravel/ai` ^1.4 (now a direct requirement).
