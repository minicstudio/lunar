- Product import: per-column number and date formats from the AI, shop exports (variant rows, separate variants files, sale prices, up-sells and cross-sells, images), and several files per import (LFP-954). Exports are read through conventions described per column, without any platform list or choice: a row type column whose types the AI gives meanings (product with one variant, product with variant rows, variant, not imported, not shippable), parent references by ID, `id:N`, or SKU across files, option pairs that variant rows number differently, packed list items whose `:`-separated parts are named, skipped, or kept, coded status, stock, backorder, and shippable values, and image URLs with a size suffix. Staff can change these conventions in the mapping step, and profiles keep them. Every cell is cleaned first (formula escape apostrophes, literal `\n` in descriptions, HTML entities in names). Option names and properties from cells are reviewed with the categories and brands; the import also writes tags, GTIN, MPN, dimensions, purchasability, and sale and compare prices, adds up-sells and cross-sells, and then downloads the images from public HTTP and HTTPS addresses only (`product-import.images.*`).
