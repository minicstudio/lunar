## 2026-11-02

- Fixed the Average Order Value dashboard chart so guest orders are included in the default customer group average when registered and guest orders share the same month. Previously the chart kept only the registered-customer average for that month, so a new guest order could leave the series unchanged.
- Average Order Value now uses total order value after discounts and without shipping costs (same basis as Order Values by Status), and shows the same helper text under the heading.
- Orders / Sales Report now uses the same order-value basis (after discounts, without shipping) for the sales series, and shows the same helper text under the heading.
