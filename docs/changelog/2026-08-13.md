## 2026-08-13

- Contact Details admin (`ContactInfoResource`): intro, street, city, and country use translatable fields; phone, email, postal code, and country code remain single shared values. Existing plain-string values for the translatable fields are wrapped into the default language when the edit form is opened.
- Content admin resources can be enabled or disabled per shop via `lunar.content.resources` in `config/content.php` (announcement, hero, menu_item, popup, faq_item, contact_info). `ContentPlugin` only registers enabled resources on the Filament panel.
- The Content (Conținut) Filament sidebar group is collapsed by default.
- Announcement banner text uses a simplified rich editor (bold, italic, underline, line breaks) instead of a single-line input.
- Hero slides can be reordered by dragging on the admin list (same as FAQ items and menu items). New slides are appended; Filament reorder updates `sort_order` and clears the `content.heroes` cache.
- Content admin is gated by the `content:manage` staff permission (admins always have access). `EnsureContentPermissions` creates the permission on migrate; grant it to non-admin staff who should edit Content. Content permission labels are merged after `lunarpanel::auth` is loaded so Access Control does not lose the core permission translations.
