## 2026-10-07

- Admin media uploads (product, collection, brand) now get a URL-safe file name: the slug of the **Name** field (alt text), or of the uploaded file name when it is empty, e.g. `Piros nyári ruha` → `piros-nyari-ruha.webp`. Accents, spaces and special characters no longer end up in image URLs. A name another media of the same owner already uses gets a `-2`, `-3`, … suffix, so two uploads can no longer overwrite each other's files in a shared directory. The field's helper text (EN/HU/RO) mentions this (LFP-477).
- `lunar:media:convert-webp` also slugifies the converted file name and avoids file names used by other media of the same owner, e.g. `photo.png` next to an existing `photo.webp` becomes `photo-2.webp` instead of overwriting it (LFP-477).
- Added `Lunar\Base\MediaFileName` (shared naming rule: slug, preferred name, random name, unique suffix, rename planning for media sharing a directory) and `Lunar\Base\MediaFileNamer`, a Spatie media library file namer that slugifies every newly added file. Register it as `file_namer` in `config/media-library.php` to apply it to all uploads (LFP-477).
