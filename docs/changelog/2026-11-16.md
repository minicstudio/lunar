## 2026-11-16

- New cart config `line_match_ignored_meta_keys` (LFP-949): meta keys listed there are left out when `GetExistingCartLine` decides whether an add-to-cart increases an existing line or creates a new one. Hosts can use it for data written onto a line after it was added (e.g. search tracking), which previously made the next add of the same purchasable create a duplicate line. Defaults to `[]`, so matching is unchanged until keys are configured.
